# QualiFlow
O QualiFlow é uma extensão de navegador modular projetada para otimizar e automatizar todo o ciclo de vida do QA diretamente no Azure DevOps e em aplicações web. Alimentado por múltiplos provedores de IA (Gemini, GitHub Copilot e Groq), ele acelera desde a geração de cenários em BDD até a execução e rastreabilidade dos testes.
